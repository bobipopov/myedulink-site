# MyEduLink — Публичен сайт

Статичен уебсайт за образователния портал **[myedulink.eu](https://myedulink.eu)**, разработен от **инж. Борислав Попов** — учител по Информатика и Информационни технологии в ПМГ „Атанас Радев" — гр. Ямбол.

## За сайта

Сайтът е създаден в помощ на учениците при обучението им по Информатика и Информационни технологии. Тук ще намерите различни материали за задължителна, задължително-избираема и профилирана подготовка, разделени по предмети и класове.

За материалите са използвани одобрените от МОН учебни програми, учебници и учебни помагала по Информатика и Информационни технологии.

## Структура

```
├── index.html        # Начална страница
├── contact.html      # Страница с контакти
├── _template.html    # Шаблон за нови страници
├── styles.css        # Общи стилове (всички страници)
├── nav.js            # Логика на навигацията
└── logo.png          # Лого на MyEduLink
```

## Функционалности

- **Навигация** с анимирани падащи менюта (slide ефект при превключване)
- **Glassmorphism хедър** — полупрозрачен с blur ефект
- **Dark / Light режим** — запазва се в localStorage
- **Responsive** — адаптивен за мобилни устройства
- **Footer** — тънка лента с авторско право и бързи линкове
- **Бързи линкове** към платформата myedulink.eu

## Технологии

Чист **HTML / CSS / JavaScript** — без framework или build инструмент.
